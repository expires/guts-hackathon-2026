# ADR 0065: Test it for student moves

Date: 2026-10-18. Status: accepted. Amends ADR 0018 and W2's "student moves are not testable".

- Student moves become testable: each gets a relevant real period and two or more options, e.g. build a safety fund vs keep spending through the 2022 cost-of-living spike; weekly budget vs current pace through a term; pay off a card vs minimum payments through the 2023 rate rises.
- The sim replays the user's student profile through the period per option (same seed) and returns side-by-side outcomes in game money, like the mortgage Test it.
