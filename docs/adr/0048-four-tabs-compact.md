# ADR 0048: Four tabs, compact layout

Date: 2026-10-17. Status: accepted. Source: DIRECTION_V2.md section 3. Supersedes ADR 0016 tab list.

- Tabs: Money, Penny, Play, You. Life is no longer a tab; it is Play solo.
- Compact layout everywhere: smaller tab icons and labels, minimal padding above the home indicator, less top padding, smaller titles.
- "Ask Penny" buttons switch to the Penny tab with context loaded (no sheet).
