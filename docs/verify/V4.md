## Advisories (non-blocking)

1. USER. `Features/CharacterSelect/Views/CharacterSelectView.swift:71-80`: at accessibility-extra-extra-extra-large the title and badge share one `HStack`. "Play yourself" wraps per word and the badge breaks as "Rec-om-men ded"; the emoji column shrinks (`ax-xxxl-character-select.png`). Proposed `docs/UI_REQUESTS.md` entry:
   > CharacterSelectView / CharacterCard: at AX Dynamic Type sizes, stack the title and badge vertically (use `ViewThatFits` or `@Environment(\.dynamicTypeSize)` with `isAccessibilitySize` to switch the `HStack` to a `VStack`), and hide or shrink the emoji column, so "Recommended" and "Play yourself" do not break mid-word. Ref: docs/screens/ax-xxxl-character-select.png.
2. USER. `DesignSystem/Theme.swift:54`: `Motion.sheet` (spring 0.3/0.8) is defined but not used; sheets use the system presentation animation. Proposed entry:
   > Apply `Motion.sheet(reduceMotion:)` to sheet content transitions (event sheet, activities) or remove the constant, to match BUILD_SPEC section 1 motion rules.
3. USER. `Features/CharacterSelect/Views/CharacterSelectView.swift:40`: the hidden debug menu opens only with `onLongPressGesture`; VoiceOver users cannot reach it. Debug only. Proposed entry:
   > Add `.accessibilityAction(named: "Debug menu", actions.onVersionLongPress)` to the version label (Debug builds).
4. USER. `Features/Playground/Views/GalleryView.swift:39,43,47`: previews read `GalleryViewModel.catalog`, a ViewModel type. Not in the forbidden list, but ADR 0011 says previews use `Fixtures`. Proposed entry:
   > GalleryView previews: use a `Fixtures.Gallery.catalog` value instead of `GalleryViewModel.catalog`.
5. W6. `docs/adr/0011` implementation notes say the gallery has 65 entries; `GalleryViewModel.swift` has 63 (and `PlaygroundScreen.swift` has 63 cases). Update the count or add the missing entries.
6. BOSS. The app bundle ships `openapi.yaml` and `openapi-generator-config.yaml` as resources (Copy Bundle Resources). Not a secret, but unneeded. Exclude them in `project.yml` (`buildPhase: none` for `Lifeline/Networking/openapi*.yaml`).
7. W6/USER. `gallery-life-dead.png`: on a dead life the Rewind button stays enabled. Confirm this is intended (rewind from death) or set `canRewind` false.
