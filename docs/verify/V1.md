### 3. Probe script against the stack

- Command: `cd services/api && uv run python <scratchpad>/v1/probe.py`. The script waits 0.7 s between requests to stay under the 120 req/min limit, and retries if the connection drops while the container restarts (3 retries happened).

  - the exact error format `{"error": {"code","message","source"}}`
  - `content-type: application/json` on every error
  - that no response body contains a JSON `null`

## Observations (not failures)

- `HEAD /v1/health` returns 405. The contract does not declare HEAD.
- `ageLife` accepts and ignores a JSON body. The contract declares no request body.
- `listCharacters` accepts an invalid token and returns 200. It does not reject it with 401. This follows from the optional security setting.
- The rate limiter groups requests by client IP. All local agents share one IP, so concurrent stack tests can get 429.
- Other agents restarted the `api` container often during this verification. Stack test runs that overlap a restart fail with connection errors that have nothing to do with the contract.
